# 短篇小说九人流水线规则包

这是一个用于短篇小说生产流程的九角色规则包。它把一篇短篇小说从选题、总纲、人物、章节、正文、编辑、终稿、质检到修复拆成 9 个负责人，每个负责人只处理自己的职责范围，避免一步到位时常见的跑题、漏设定、反复推翻和质量不可控。

## 适合用途

- 放到 GitHub 作为公开/私有规则仓库
- 复制到 ChatGPT、Claude、Gemini、Kimi、通义等对话里作为分工提示词
- 接入本地网页、Agent、工作流工具或自动化脚本
- 作为短篇小说团队的标准操作流程文档

## 九个负责人

| 步骤 | 负责人 | 产物 | 交接给 |
| --- | --- | --- | --- |
| 01 | 选题定位负责人 | 选题、卖点、平台、标题、付费卡点、同款风险自查 | 02 总纲负责人 |
| 02 | 总纲负责人 | 故事总纲、三幕式结构、最终真相、原创性避雷 | 03 人物规则负责人 |
| 03 | 人物规则负责人 | 核心人物、关系网、故事规则、误导信息、隐藏真相 | 04 章节大纲负责人 |
| 04 | 章节大纲负责人 | 6-10 章章节大纲、第三章付费卡点、伏笔回收表 | 05 正文负责人 |
| 05 | 正文负责人 | 正文初稿 | 06 编辑负责人 |
| 06 | 编辑负责人 | 编辑检查、问题清单、必须修改项 | 07 终稿负责人 |
| 07 | 终稿负责人 | 项目汇总版、成品小说版 | 08 终稿质检负责人 |
| 08 | 终稿质检负责人 | 终稿质检报告 | 09 终稿修复负责人 |
| 09 | 终稿修复负责人 | 修复后的完整成品小说 | 完成 |

## 推荐工作方式

1. 先读取 `rules/01-topic-positioning.md`，生成选题定位。
2. 用户确认后，把第 1 步产物交给第 2 步。
3. 每一步只读取前置交接稿，不重新推翻前面已经确认的核心设定。
4. 第 6-9 步负责质量收束：编辑、终稿、质检、修复。
5. 每个步骤的输出都应保留清晰标题，便于合并成完整交接文档。

```text
必须基于前面已经完成的交接稿继续，不重新换题材，不推翻已确认设定。
输出内容必须带清晰标题，结尾写明交接给下一步负责人。
```
